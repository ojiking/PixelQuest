# 메탈펀치 뱀돌이 (Metal Punch: Baemdori) — 살아있는 기획서

> 웹 프로토타입으로 가설을 검증하면서 이 문서를 계속 갱신합니다.
> 실행: `python app.py` 후 `http://localhost:5000/game` (또는 `static/game/index.html`을 아무 정적 서버로 열기)

---

## 1. 한 줄 컨셉
**블록으로 변해버린 도시를 동료 로봇과 함께 청소하는 벨트스크롤 로그라이트.**
죽어도 모은 부품으로 동료 로봇을 개조해서 다시 출동한다.

## 2. 핵심 기둥 (Pillars)
| # | 기둥 | 검증 질문 |
|---|---|---|
| P1 | **때리는 맛** | 히트스톱, 넉백, 부위 파괴가 손맛을 주는가? |
| P2 | **동료 키우기** | 볼트가 강해지는 게 체감되고, 다음 런을 하고 싶게 만드는가? |
| P3 | **생김새 = 행동** | 처음 보는 적도 외형만 보고 행동을 예측할 수 있는가? |
| P4 | **공정한 난이도** | 죽었을 때 "내 실수"로 느껴지는가? (예고 동작, 보이는 함정) |
| P5 | **블록 바이옴** | 색과 블록 구성만으로 스테이지가 다르게 느껴지는가? |

## 3. 세계관 초안 (오리지널)
- **블록 쇼크**: 어느 날 도시의 물질이 1m 블록 단위로 굳어버린 재해.
- 플레이어는 민간 복구 업체 **'청소반'**의 신입 **뱀돌이**. 날렵하고 비열하게 싸워서 붙은 별명. 무너진 구역을 점거한 폭력 조직 **'철거단'**을 몰아내며 구역을 정화한다.
- 동료 **볼트**는 청소반의 낡은 작업 로봇. 적에게서 회수한 **부품(⚙)**으로 개조한다. → 성장 시스템과 세계관이 자연스럽게 연결됨
- 적이 맞으면 블록 조각으로 흩어지는 것도 "블록화된 세계"의 규칙으로 설명 → 잔인함은 줄이고 쾌감은 유지

## 4. 현재 프로토타입 (v0.1) 내용
**게임 루프**: 타이틀 → 런(스테이지 2개) → 스테이지 사이 특성 선택 → 결과(부품 정산) → 정비소(업그레이드) → 다음 런

| 적 AI | 공격 토큰(플레이어에게 동시에 2명만 공격) + 대기 링, 위험 공격은 빨간 깜빡임 예고 |
| 동료 볼트 | 주인공과 서로 충돌하지 않음(겹쳐 지나감 — 진로 방해 방지), 전술 3종(돌격/호위/협공), 다운 시 9초 후 자가 수리, 회전 차기, 구조 프로토콜 |

| 부위 세분화 | 머리 / 몸통 / 위팔·아래팔 / 허벅지·정강이. 손목만, 팔 전체, 정강이만 잘리는 등 조합이 다양 |
| 파괴 방식 | 절단(덩어리로 날아감) · 타격(멀리 튕겨 나감, 홈런) · 분쇄(그 자리에서 박살) · 허리 절단(상·하반신 분리) |
| 핏자국 | 튀는 피 입자(출혈·절단·폭발 시 붉은 단면 복셀)가 실제로 날아가 닿은 곳에 묻음. **배경**: 스테이지 전체를 덮는 3D 핏자국 맵(10cm 칸)에 직접 칠하고 바닥·벽·차·쓰레기통 표면이 그 색을 읽어 그림 → 아무리 많이 묻어도 그리는 비용이 늘지 않음. 바닥에 떨어지면 얼룩(빠를수록 길게 번짐), 벽 옆면에 부딪히면 그 자리에 자국 — 스테이지 끝까지 유지(최대 6000개, 오래된 것부터 교체). **캐릭터**: 맞은 높이의 부위(머리/몸통·팔/허벅지/정강이)에 반 복셀 단위 얼룩이 번짐. 주인공·볼트는 약 9초에 걸쳐 듬성듬성 사라지며 원래 색으로, 살아 있는 적은 아주 천천히, 시체는 그대로. 피의 50%는 캐릭터를 통과해 뒤로 날아감. **과장 연출**: 실제 튄 양보다 크게 — 바닥 얼룩 2.4배 + 주변 방울 2~5개 + 빠를수록 길게 번짐, 벽 자국 2.2배 + 주변 방울 + 아래로 흘러내리는 줄기, 주인공·볼트는 한 방울에 부위의 20%가 물들고 옆 부위로 45% 번짐. 살아 있는 적은 누군지 알아볼 수 있게 한 방울 6%, 번짐 15%, 부위당 최대 28%까지만(시체는 제한 없음). 수치는 config.js BLOOD (최대 18000개) |

### 광기 액션 아이디어 (사용자 승인됨 — 다음 구현 후보, 볼트 합체기는 제외)
1. ✅ **피칠갑 광폭화** (v0.6.12 구현) — 뱀돌이 몸에 묻은 피의 양(실제 값, 화면 표시는 상한 있음)이 광폭 게이지. 광폭 표시는 빨간색이 아니라 하얀 눈빛·김으로(주인공을 놓치지 않게). 온몸이 물들면 광폭화(맨주먹 절단 판정, 공격 속도↑, 화면 살짝 붉게), 피가 마르면 종료. (추천 1순위)
2. **처형기** — 빈사 상태 적을 잡으면 처형 모션(머리 뽑기, 반으로 찢기, 머리 처박기). 처형 중 무적, 큰 고어 보너스.
3. **인간 무기(자이언트 스윙)** — 잡은 적을 통째로 휘둘러 주변을 쓸어버림. 휘두를수록 부위가 떨어져 나감.
4. **환경 처형** — 가시 함정에 꽂기, 전봇대에 박기, 차 유리창 뚫기, 낭떠러지로 던지기 → 특수 연출 + 보너스.
5. **볼링 콤보** — 날아간 몸 하나가 쓰러뜨린 적 수만큼 보너스 배율 (큰 글씨 대신 동전 수로 표현).
7. **머리 없는 몸** — 머리가 잘린 몸이 몇 걸음 비틀거리다 쓰러짐, 팔 잘린 적은 겁먹고 도망.
8. **무기 마지막 일격** — 내구도 마지막 한 방이 강해지고 무기가 파편으로 터지며 주변 피해.
9. **마지막 적 슬로모션** — 구역 마지막 적 처치 순간 0.5초 슬로우 + 살짝 줌 (글씨 없이).
- 추천 시작 조합: 1 + 2 + 7
