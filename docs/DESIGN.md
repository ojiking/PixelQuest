# 메탈펀치 뱀돌이 (Metal Punch: Baemdori) — 살아있는 기획서

> 웹 프로토타입으로 가설을 검증하면서 이 문서를 계속 갱신합니다.
> 실행: `python app.py` 후 `http://localhost:5000/game` (또는 `static/game/index.html`을 아무 정적 서버로 열기)

---

## 1. 한 줄 컨셉
**블록으로 변해버린 도시를 동료 로봇과 함께 청소하는 벨트스크롤 로그라이트.**
죽어도 모은 부품으로 동료 로봇을 개조해서 다시 출동한다.

## 2. 핵심 기둥 (Pillars)
| # | 기둥 | 검증 질문 |
|---|---|---|
| P1 | **때리는 맛** | 히트스톱, 넉백, 부위 파괴가 손맛을 주는가? |
| P2 | **동료 키우기** | 볼트가 강해지는 게 체감되고, 다음 런을 하고 싶게 만드는가? |
| P3 | **생김새 = 행동** | 처음 보는 적도 외형만 보고 행동을 예측할 수 있는가? |
| P4 | **공정한 난이도** | 죽었을 때 "내 실수"로 느껴지는가? (예고 동작, 보이는 함정) |
| P5 | **블록 바이옴** | 색과 블록 구성만으로 스테이지가 다르게 느껴지는가? |

## 3. 세계관 초안 (오리지널)
- **블록 쇼크**: 어느 날 도시의 물질이 1m 블록 단위로 굳어버린 재해.
- 플레이어는 민간 복구 업체 **'청소반'**의 신입 **뱀돌이**. 날렵하고 비열하게 싸워서 붙은 별명. 무너진 구역을 점거한 폭력 조직 **'철거단'**을 몰아내며 구역을 정화한다.
- 동료 **볼트**는 청소반의 낡은 작업 로봇. 적에게서 회수한 **부품(⚙)**으로 개조한다. → 성장 시스템과 세계관이 자연스럽게 연결됨
- 적이 맞으면 블록 조각으로 흩어지는 것도 "블록화된 세계"의 규칙으로 설명 → 잔인함은 줄이고 쾌감은 유지

## 4. 현재 프로토타입 (v0.1) 내용
**게임 루프**: 타이틀 → 런(스테이지 2개) → 스테이지 사이 특성 선택 → 결과(부품 정산) → 정비소(업그레이드) → 다음 런

| 시스템 | 구현 내용 |
|---|---|
| 조작 | 이동(8방향, 라인 이동), 3타 콤보, 점프, 날아차기, 줍기/던지기 |
| 타격감 | 히트스톱, 화면 흔들림, 넉백/다운/기상 무적, 백어택 x1.5 |
| 부위 파괴 | 머리/양팔/양다리 개별 체력. 파괴 시 복셀 파편으로 분해 |
| 부위 파괴 → 행동 변화 | 팔 없음 → 발차기만 / 투척병 팔 없음 → 근접형 전환 / 다리 하나 → 느려짐 / 다리 없음 → 기어감, 돌진 불가 / 머리 → 즉사 |
| 적 9종 | 골목 깡패(포위), 돌격 헬멧(예고 후 돌진), 벽돌 배달부(거리 유지+투척), 철거 덩치(슈퍼아머+내려찍기), 폭죽 꼬마(돌진 자폭, 죽어도 폭발), **맨홀 방패병**(정면 방어·방패 밀치기, 뒤잡기/위에서/폭발·화염/가드 브레이크로 공략, 방패 팔을 자르면 맨홀 뚜껑 획득), **그림자 닌자**(체력 낮음·재빠름, 원거리 표창·근접 닌자도, 재주넘기 회피, 처치 시 닌자도 획득), **폭주족**(도심 전용·오토바이 탑승: 라인을 맞추고 부릉부릉 예고 후 직선 돌진, 경로 위 아군 적까지 치어버림 → 지나쳐서 유턴. 넘어뜨리거나 14 이상 피해·폭발·다리 절단 시 낙차 → 체인/배트/파이프를 꺼내 맨몸 싸움. 차나 벽에 정면충돌하면 스스로 낙차), 보스 2종 |
| 보스 | **마지막 스테이지의 마지막 구역에만** 등장, 매 런 둘 중 무작위. **철거반장 굴삭**(2페이즈, 지원 호출) / **사이보그 폭주왕 쇠톱** — 붉은 모히칸·금속 반쪽 얼굴·기계 팔에 전기톱. ①오토바이 페이즈: 슈퍼아머 돌진, 전기톱을 내밀고 지나가며 베어버림, 주차된 차를 들이받아 폭파하며 관통 → 정차(부릉부릉)·유턴 순간이 공격 기회 ②체력 65%↓: 오토바이를 걷어차 던짐(폭발) + 폭주족 2명 호출 → 도보로 전기톱 돌진(밀고 들어오며 갈아냄)·전기톱 가로베기·내려찍기·돌진 ③체력 30%↓: 폭주 모드(공격 속도 1.3배, 몸에서 불꽃, 폭주족 추가). **전기톱 팔을 자르면 전기톱을 떨어뜨려 플레이어가 주워 쓸 수 있음** (보스는 맨손 공격만 남음) |
| 난이도 곡선 | 런 진행도 t(첫 구역 0 → 보스 직전 1)에 따라 적 구성이 바뀜. 등장 시점: 깡패·배달부(0) → 돌격 헬멧(.15) → 폭죽 꼬마(.3) → 방패병(.45) → 덩치(.6) → 닌자(.75) → 폭주족(.9, 도심에서 더 자주). 새 적은 처음 나오는 구역 첫 웨이브에 반드시 1명 포함 + '새로운 적: 이름' 안내. 등장 가중치는 진행에 따라 변함(깡패 비중 6→2.2로 감소). 웨이브 크기 3→6.5명, 구역당 웨이브 2→3개. 수치는 config.js ENEMY_CURVE / WAVE_CURVE |
| 적 AI | 공격 토큰(플레이어에게 동시에 2명만 공격) + 대기 링, 위험 공격은 빨간 깜빡임 예고 |
| 동료 볼트 | 주인공과 서로 충돌하지 않음(겹쳐 지나감 — 진로 방해 방지), 전술 3종(돌격/호위/협공), 다운 시 9초 후 자가 수리, 회전 차기, 구조 프로토콜 |
| 무기 15종 + 적 전용 2종(닌자도, 맨홀 뚜껑: 들고 있으면 정면 피해 60% 감소) | 무기마다 모션과 파괴 방식이 다름 (아래 표). 내구도, 던지기 |
| 부위 세분화 | 머리 / 몸통 / 위팔·아래팔 / 허벅지·정강이. 손목만, 팔 전체, 정강이만 잘리는 등 조합이 다양 |
| 파괴 방식 | 절단(덩어리로 날아감) · 타격(멀리 튕겨 나감, 홈런) · 분쇄(그 자리에서 박살) · 허리 절단(상·하반신 분리) |
| 핏자국 | 튀는 피 입자(출혈·절단·폭발 시 붉은 단면 복셀)가 실제로 날아가 닿은 곳에 묻음. **배경**: 바닥에 떨어지면 얼룩(빠를수록 길게 번짐), 벽 옆면에 부딪히면 그 자리에 자국 — 스테이지 끝까지 유지(최대 6000개, 오래된 것부터 교체). **캐릭터**: 맞은 높이의 부위(머리/몸통·팔/허벅지/정강이)에 반 복셀 단위 얼룩이 번짐. 주인공·볼트는 약 9초에 걸쳐 듬성듬성 사라지며 원래 색으로, 살아 있는 적은 아주 천천히, 시체는 그대로. 피의 35%는 캐릭터를 통과해 뒤로 날아감 |
| 트로피 | 떨어진 부위와 시체는 스테이지 끝까지 남음. 맨손 L로 집어 던질 수 있음 (피해 4, 움찔) |
| 신체 무기 | 집어 든 팔·다리·머리는 J로 휘두름 (고유 콤보·내구도, 다 쓰면 박살). 몸통·상하반신은 던지기만 |
| 지형 | 높이 맵: 낭떠러지(떨어지면 적·플레이어 모두 사망), 올라설 블록(1칸), 넘을 수 없는 벽(2칸) |

| 화염 스프레이 | J 누르는 동안 불길 분사 (2.6m 원뿔) | 맞은 적은 3초간 불타며 지속 피해, 불타 죽으면 시커멓게. 드럼통 점화. 연료가 떨어지면 버림 |
| 쌍절곤 | 빠른 연타 3번 → 몸을 돌리는 회전 마무리 (사슬로 이어진 두 번째 막대가 휘둘러짐) | 타격, 한 방은 약하지만 빠름, 내구도 높음 |
| 철퇴 | 묵직한 내려찍기 2타 → 강타 (사슬 끝 가시 쇠공이 휘어 들어옴) | 분쇄, 위력 높고 조금 느림 |
| 채찍 | 아주 긴 사거리 채찍질 2타 → 끌어당기기 | 절단(팔 집중), 마무리로 적을 내 앞으로 끌어옴 |
| 곡괭이 | 내려찍기 2타 | 분쇄, 머리 집중 (헤드 크러시) |

## 6. 수치 조정 가이드
모든 기획 수치는 `static/game/js/config.js` 한 곳에 있습니다.

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 공격 선딜/판정/후딜, 데미지, 넉백, 히트스톱 | `ATTACKS` |
| 적 체력/속도/크기/드롭 | `ENEMIES` |
| 스테이지별 적 등장 비율 | `SPAWN_POOLS` |
| 무기 성능/내구도/부위 파괴력 | `WEAPONS` |
| 볼트 기본 성능, 전술 | `BOT` |
| 바이옴 색 | `BIOMES` |
| 특성 / 업그레이드 비용 | `PERKS` / `UPGRADES` |

테스트 단축키: **B** 적 무작위 소환, **P** 픽셀 크기 변경

## 8. 열린 질문
- 볼트가 너무 강하면 플레이어가 구경꾼이 된다. 볼트의 역할은 "딜러"인가 "서포터"인가?
- 부위 파괴 확률을 무기 종류로 차별화할 것인가, 공격 방향(위/아래)으로도 나눌 것인가?
- 런 길이: 스테이지 2개(프로토타입) → 최종 몇 개? (예: 4바이옴 + 최종 보스)
- 메타 성장의 상한: 업그레이드를 다 사면 그 다음 동기는? (볼트 외형 커스터마이즈, 새 동료 등)
